# Multimedia Laboratory

An academic multimedia workspace with a static Astro frontend for browser-based image, audio, and video metadata inspection.

The original cluster directories remain available for future laboratory assignments. The web interface lives in [`frontend/`](./frontend/README.md) and processes selected media locally—files are not uploaded to an application server.

Production: https://multimedia-laboratory-nu.vercel.app

## Quick start

```powershell
cd frontend
npm install
npm run dev
```

See the frontend README for architecture, testing, supported formats, and limitations.
